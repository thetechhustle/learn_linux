# Chapter 01: Where to Start

This chapter sets the operating baseline for the rest of the course. Before you change services, install packages, debug boot failures, or manage users, you need a reliable way to identify the system in front of you, find trusted documentation, understand command notation, and choose a safe lab environment.

By the end of this chapter, you should be able to:

- Describe the core responsibilities of a system administrator.
- Identify the Linux distribution and release you are working on.
- Read command syntax, paths, prompts, units, and examples consistently.
- Use local man pages and vendor documentation before relying on search results.
- Choose an appropriate place to practice, from a local VM to a small cloud instance.
- Decide which adjacent topics deserve deeper study for your target role.

Work through the lessons in order if you are new to Linux administration. If you already have shell experience, focus on the documentation, notation, software installation, and hosting lessons; those topics prevent many avoidable mistakes later in the course.

Use a disposable lab system for experimentation. Chapter 01 is mostly orientation, but the habit matters: inspect first, record what you saw, make one reversible change, and verify the result. That evidence trail is the difference between casual command running and professional operations work.
